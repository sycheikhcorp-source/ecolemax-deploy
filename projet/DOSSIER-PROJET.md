# Projet « ÉcoleMax » — Application scolaire par IA pour le Sénégal & l'Afrique, ambition mondiale

---

## 1. Le projet en 1 minute

**ÉcoleMax** est une application mobile (Android + iOS) qui centralise **tout ce dont un élève a besoin** :

- **Exercices, cours et annales** pour **toutes les matières** du programme **sénégalais et français** (Primaire, Collège, Lycée, Bac).
- Un **assistant IA ultra-performant** qui corrige les exercices **avec très peu d'erreurs**, explique les notions, **fait des recherches sur internet**, aide à **rédiger des dissertations**.
- **Multilinguisme** : interface et cours en **français, anglais, espagnol, allemand, portugais et wolof**, avec **onglet de traduction** — porte ouverte sur l'Europe.
- **SÉCURITÉ TOTALE** : **anti-plagiat**, **anti-capture d'écran**, **anti-partage**, **anti-téléchargement hors ligne** du contenu protégé.
- **Design moderne, fluide et simple** : un outil beau et intuitif, pensé pour tous les élèves.
- Un **tableau de bord complet** pour gérer l'application **à distance**.

**Notre angle :** appli **compacte**, **ultra-simple**, **IA comme tuteur personnel** dans 6 langues, **contenu protégé**, prix accessibles.

## 7. SÉCURITÉ — protection complète du contenu

### 1. Anti-plagiat (rédactions & dissertations)
- **Vérification des rédactions** : l'IA compare le texte soumis avec internet (recherche d'extraits similaires).
- **Citation des sources** obligatoire si l'élève utilise des documents.
- **Alertes** : pourcentage de similarité affiché, historique, blocage si plagiat confirmé.
- **Protection du contenu ÉcoleMax** : chaque exercice/cours est **chiffré et watermarké** ; une recherche d'extraits en ligne permet de détecter si un contenu protégé est partagé.

### 2. Anti-capture d'écran
- **Android** : `FLAG_SECURE` bloque screenshots & enregistrement d'écran.
- **iOS** : `react-native-screenshot-proof` / composants sécurisés.
- **Watermark dynamique** : chaque écran affiche un filigrane invisible/visible avec **pseudo + date + heure** → dissuasion + traçabilité.
- **Détection** : callback sur capture → notification à l'admin + log.
- **Pas d'export PDF / partage de page** : le bouton « partager » est remplacé par une option « signaler un problème ».

### 3. Anti-partage
- **Watermark unique par utilisateur** : chaque contenu vu par un élève porte son pseudo (visible et/ou incrusté) → tout partage est traçable.
- **Pas de copier-coller** : texte des cours et corrections désactivé (selection désactivée dans SecureView).
- **Lien de partage inefficace** : l'accès à un cours se fait **toujours via authentification** ; aucun lien public.
- **Détection de partage en ligne** : recherche web périodique des extraits de contenus → alerte admin.
- **Chiffrement** : contenu en transit (TLS 1.3) et au repos (AES-256).

### 4. Anti-téléchargement hors ligne
- **Accès au téléchargement réservé aux plans Illimité** (packs). Plans 250 et 500 : **pas de téléchargement**.
- Pour les plans Illimité : téléchargement **chiffré** (AES-256), déchiffrage **exclusivement dans l'appli** (SecureView).
- **Suppression automatique** après expiration de l'abonnement.
- **Pas de stockage brut** : les fichiers ne sont pas lisibles hors de l'appli.
- **Lien temporaire** : le contenu est servi via des liens signés/expirants.

### 5. Droits & authentification côté serveur
- **JWT / sessions** : chaque requête vérifie plan + expiration.
- **Rate limiting** : protection anti-abuse.
- **Logs d'accès** : tout accès à un contenu est enregistré (qui, quoi, quand).
- **2FA** pour l'administrateur du dashboard.
- **Rôles** : admin / éditeur de contenu.

### Stack technique de sécurité
- `react-native-screenshot-proof` (capture)
- `react-native-secure-view` / SecureView custom (watermark + désactivation copier)
- Watermark dynamique (canevas React Native)
- Chiffrement : AES-256 + gestion des clés côté serveur
- Recherche anti-plagiat : Tavily / Brave + similarité texte
- Logs centralisés + alertes admin (push)

## 8. Stratégie IA — assistant ultra-performant, corrections parfaites

### Modèles choisis
| Besoin | Modèle suggéré |
|---|---|
| Correction & dissertation | GPT-4o / Claude / Gemini |
| Questions simples & volume | GPT-4o-mini / Groq |
| Traduction | modèle spécialisé (Gemini/DeepL) |
| OCR (photo du cahier) | Tesseract / Google Vision |
| Recherche internet | Tavily / Brave Search API |

### Techniques anti-erreurs
1. **Vérification systématique (self-check)** : maths/physique — recalcul + double méthode.
2. **Sortie structurée** : JSON (réponse, étapes, explication, confiance).
3. **Few-shot** : exemples du programme sénégalais/français.
4. **Pas-à-pas obligatoire** : aucune étape sautée.
5. **Sources citées** : pas d'hallucination.
6. **Langue cible dans la requête**.
7. **Score de confiance** : seuil → reformulation.
8. **Retour utilisateur** (👍/👎) → amélioration continue.

## 9. Architecture technique

### Frontend
- **Expo (React Native)** : écrans Accueil, Exercice, IA, Traduction, Forum, Profil.
- **SecureView** : composant sécurisé (watermark, désactivation capture/copier).
- **Dashboard admin** : PWA React (accessible PC + mobile pour gestion à distance).

### Backend
- Node.js (Express) ou Python (FastAPI).
- PostgreSQL (ou Firebase au début).
- **Sécurité** : JWT, rate limiting, chiffrement, logs, 2FA.
- **File d'attente** : OCR, génération de contenu IA.

### IA & recherche
- OpenAI / Gemini / Groq + Tavily/Brave Search + Tesseract/Google Vision.

### Paiements
- **Wave** (wave.sn) : liens de paiement + API + facturation.
- **Orange Money** : API paiement / demande de paiement.
- Free Money / Airtel Money / PayDunya (phase 2–3).

### Hébergement
- Render / Fly.io / Railway (~$7/mois).
- Supabase / PostgreSQL.
- Domaine ~10 000 FCFA/an.

### Schéma de données principal
- `users` : id, pseudo, niveau, ville, langue, plan, expiration, status, parrain.
- `subscriptions` : id, user_id, plan, montant, canal, lien, date_paiement, status.
- `payment_links` : id, plan, canal, url, statut.
- `subjects / chapters / exercises` : contenu (chiffré, watermarké, approuvé).
- `ai_usage` : user_id, action, tokens, cout, score_confiance.
- `security_logs` : captures, partages, plagiats, accès anormaux.
- `schools`, `promo_codes`, `referrals`, `admin_logs`.
