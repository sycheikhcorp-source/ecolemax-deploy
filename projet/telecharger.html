Installer ÉcoleMax

L'application officielle — cours, exercices, quiz et professeur IA pour réussir à l'école.

Télécharger l'application (Android)

Version 2.4.5 · 188 Ko · Android 7 et supérieur

✓ Installable sur tous les Android récents ✓ Sans publicité ✓ Aucune donnée revendue
Fonctionne sur téléphone ET ordinateur.
Le même compte vous donne accès à l'application Android, au site web ecolemax.onrender.com et à l'espace élève — vos résultats vous suivent partout.

1 Installer sur un téléphone Android

1
Appuyez sur « Télécharger l'application » Le fichier ÉcoleMax.apk se télécharge. Il fait environ 99 Ko.
2
Ouvrez le fichier téléchargé Cherchez « ÉcoleMax.apk » dans vos notifications ou dans le dossier Téléchargements.
3
Autorisez l'installation Android affiche « Installation bloquée » ou « Source inconnue ». Appuyez sur Paramètres puis activez « Autoriser depuis cette source ». Revenez en arrière.
4
Appuyez sur « Installer » L'installation prend quelques secondes.
5
Ouvrez ÉcoleMax L'icône apparaît sur votre écran d'accueil.
⚠️ TRÈS IMPORTANT — Désinstallez l'ancienne version avant d'installer celle-ci.

Si vous avez déjà installé une ancienne ÉcoleMax (elle se fermait toute seule), désinstallez-la d'abord : appui long sur l'icône ÉcoleMax → Désinstaller. Ensuite seulement, installez la nouvelle version 2.4.5.

Sans cette étape, Android peut refuser l'installation ou conserver l'ancienne application.

Si une erreur survient malgré tout, elle s'affiche à l'écran au lieu de fermer l'application — faites une capture d'écran et envoyez-la.

2 Créer votre compte

1
Appuyez sur « S'inscrire » Choisissez un pseudo, un e-mail, un mot de passe et votre niveau scolaire.
2
Notez votre CODE DE RÉCUPÉRATION Un code du type 4A7F-9C21 s'affiche. Faites une capture d'écran. Il vous permettra de retrouver votre compte si vous oubliez votre mot de passe.
3
C'est parti ! Votre essai gratuit de 48 heures est activé immédiatement. Aucune carte bancaire.
Votre compte vous suit partout.
Le même pseudo et le même mot de passe fonctionnent sur le téléphone Android, sur un autre téléphone et sur un ordinateur. Vos résultats sont synchronisés en temps réel.

3 Mot de passe oublié ?

Deux solutions, dans cet ordre :

A
Vous avez votre code de récupération Sur l'écran de connexion, appuyez sur « Mot de passe oublié ? ». Saisissez votre pseudo, puis votre code de récupération. Un nouveau mot de passe s'affiche : notez-le.
B
Vous avez perdu le code Contactez votre professeur. Il peut générer un nouveau mot de passe et un nouveau code depuis le tableau de bord administrateur, en quelques secondes. Votre compte et vos résultats sont conservés.
Aucun élève ne peut perdre définitivement son compte. L'administrateur peut toujours rétablir l'accès.
