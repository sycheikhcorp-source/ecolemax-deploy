01 Présentation

ÉcoleMax est une plateforme éducative complète conçue pour les écoles, collèges et lycées. Elle permet aux élèves d'accéder à des exercices, quiz, cours et assistance IA depuis leur téléphone Android ou leur navigateur web, avec un dashboard administrateur centralisé pour le gestionnaire d'établissement.

05 Installation
  1. Télécharger l'APK depuis le lien fourni par l'établissement
  2. Autoriser l'installation depuis « Sources inconnues » dans les paramètres Android
  3. Ouvrir l'application ÉcoleMax
  4. Créer un compte avec pseudo et mot de passe
  5. Commencer les exercices, quiz et consultation de l'assistant IA

12 Résumé

ÉcoleMax est une plateforme éducative complète, prête pour les tests avec des vrais élèves. Elle offre une application Android installable, un site web responsive, et un dashboard administrateur centralisé. Les comptes sont synchronisés entre tous les points d'accès. La plateforme est déployée sur Render avec une base de données centralisée pour une synchronisation instantanée.

✅ Version livrée : testée, fonctionnelle, prête pour 50+ élèves simultanés.
