| Les données sont-elles chiffrées en transit ? | **Oui** |
| L'utilisateur peut-il demander la suppression ? | **Oui** |
| Données collectées | **Nom/identifiant** → collecté, obligatoire, but : gestion du compte |
| | **Adresse e-mail** → collectée, obligatoire, but : gestion du compte |

## ❓ Questions probables de la revue Google

**« Pourquoi l'application a-t-elle besoin d'Internet ? »**
→ Elle synchronise les cours, les exercices et le compte de l'élève avec notre serveur.

**« L'application est-elle une simple copie d'un site web ? »**
→ Non. Le contenu pédagogique est **embarqué dans l'application** : elle démarre instantanément
et l'interface reste accessible hors connexion. Seules les données du compte (progression,
résultats) sont synchronisées.

**« Comment un utilisateur supprime-t-il son compte ? »**
→ Dans l'application : **Profil → Supprimer mon compte**. La suppression est immédiate et
définitive. La procédure est aussi décrite sur
https://ecolemax.onrender.com/confidentialite

**« L'application collecte-t-elle des données d'enfants ? »**
→ L'application est un outil scolaire. Elle ne collecte que le pseudo, l'e-mail et le niveau
scolaire, sans publicité ni traceur. Les parents peuvent demander la suppression à tout moment.
